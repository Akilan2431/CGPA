# 🎓 Telegram GPA Calculator Bot

A simple **Flask-based Telegram bot** that helps students calculate their **Grade Point Average (GPA)** by entering subject grade points and credit points directly through Telegram.

---

## ✨ Features

* 📚 Calculate GPA for any number of subjects.
* 🤖 Interactive Telegram bot interface.
* 📝 Step-by-step input for grade points and credit points.
* 🧮 Automatic GPA calculation.
* ✅ Input validation and error handling.
* 🔄 Restart the calculation anytime using the `/start` command.

---

## 🛠️ Tech Stack

* Python
* Flask
* Telegram Bot API
* Requests

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Akilan2431/CGPA.git
cd CGPA
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Create a Telegram Bot

1. Open Telegram and search for **@BotFather**.
2. Run the `/start` command.
3. Create a new bot using `/newbot`.
4. Copy the bot token provided by BotFather.

### 4. Configure the Bot

Open `app.py` and replace the existing token with your own Telegram Bot Token.

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

## 🌐 Deployment

Deploy the Flask application to any supported hosting platform such as:

* PythonAnywhere
* Render
* Railway
* Heroku (legacy support)

After deployment, configure the Telegram webhook:

```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOUR_DEPLOYED_URL>
```

---

## 💻 Running Locally Using ngrok

If you prefer to run the application from your own computer:

1. Install Python and required packages.

```bash
pip install flask requests
```

2. Start the Flask application.

3. Launch ngrok.

```bash
ngrok http 5000
```

4. Copy the HTTPS forwarding URL generated by ngrok.

5. Register the webhook.

```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<NGROK_URL>
```

6. Open Telegram and start chatting with your bot.

> **Note:** When using ngrok, your bot will work only while your computer and the Flask server are running.

---

## 📱 Usage

1. Send `/start`.
2. Enter the number of subjects.
3. Enter the grade point for each subject.
4. Enter the credit point for each subject.
5. Receive your calculated GPA instantly.

You can restart the process anytime by sending `/start`.
